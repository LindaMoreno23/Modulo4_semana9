Al ejecutar el comando node server.js, Node.js inicia la aplicación y deja el servidor
 disponible para recibir solicitudes desde el navegador.

En la terminal aparece el mensaje: "Servidor ejecutándose en puerto 3000", 
lo que indica que el servidor está funcionando correctamente.

Al ingresar a la ruta /estado, el servidor responde con un objeto en formato JSON 
que informa el estado del servicio y confirma que la API comunitaria está operando 
normalmente.
